# Security policy

## Supported versions

Only the latest release of the packages `UpInBlue.Leonardo.WinUI`, `UpInBlue.Leonardo.Wpf` and
`UpInBlue.Leonardo.Check` receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Use the private vulnerability reporting of this repository: open the tab
**Security**, then **Report a vulnerability**. You get an answer within a few working days.
